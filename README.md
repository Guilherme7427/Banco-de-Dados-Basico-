## 📖 Sobre o Repositório

Bem-vindo(a) ao **SQL Essentials**! Este repositório foi criado para documentar e consolidar os conceitos fundamentais de Banco de Dados Relacionais e a linguagem **SQL** (Structured Query Language). 

Todos os scripts, consultas e modelagens deste repositório foram desenvolvidos e testados utilizando o ambiente gráfico do **MySQL Workbench**.

---

## 🗂️ Conteúdo Programático

O repositório está dividido nos seguintes tópicos essenciais:

| Módulo / Categoria | Descrição | Principais Conceitos / Comandos |
| :--- | :--- | :--- |
| **01. Introdução ao DDL** | Criação e alteração da estrutura do banco de dados. | `CREATE DATABASE`, `CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`. |
| **02. Manipulação de Dados (DML)** | Inserção, atualização e exclusão de registros. | `INSERT INTO`, `UPDATE`, `DELETE`. |
| **03. Consultas Básicas (DQL)** | Filtragem e recuperação de dados. | `SELECT`, `FROM`, `WHERE`. |
| **04. Ordenação e Filtros** | Refinando os resultados das buscas. | `ORDER BY` (ASC/DESC), `LIKE`, `IN`, `BETWEEN`, `IS NULL`. |
| **05. Funções de Agregação** | Cálculos e estatísticas sobre os dados. | `COUNT()`, `SUM()`, `AVG()`, `MAX()`, `MIN()`. |
| **06. Agrupamento** | Agregando dados por categorias. | `GROUP BY`. |
| **07. Junções** | Relacionando dados de múltiplas tabelas. | `INNER JOIN`. |
| **08. Modelagem e Constraints** | Garantindo a integridade dos dados. | Chaves Primárias (`PRIMARY KEY`), Chaves Estrangeiras (`FOREIGN KEY`), `UNIQUE`, `NOT NULL`. |
